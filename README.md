# 待辦事項

Microsoft To Do 的替代品：自訂清單、我的一天、重要、到期日、提醒、重複、步驟、備註，桌面小工具可以切換清單、直接打勾。
手機、電腦網頁、語音總控用的是同一份資料，任何一邊改了，其他地方幾秒內就會更新。

## 安裝
1. 手機瀏覽器打開 GitHub `hoonsor/APK-Todo` 的 Releases，下載 `Todo-latest.apk`（新功能先裝 `Todo-LAB-latest.apk`，兩個可以同時安裝）；或用 Obtainium 追蹤這個 repo
2. 允許「安裝未知應用程式」後安裝；之後在 APP 的「設定與健康檢查」最下面可以直接檢查更新

## 第一次使用
1. **登入**：輸入 Email → 收信裡的驗證碼 → 登入
2. **開通帳號**：第一次登入後畫面會顯示「帳號尚未開通」，請把設定頁上的「使用者 ID」告訴 Claude（或自己在 Supabase 的 `todo_members` 加一列），開通後按「立即同步」
3. **設定與健康檢查**（清單總覽右上角齒輪）逐項變綠燈：
   - 通知權限、精準提醒、電池最佳化設為「不最佳化」
   - ColorOS：手機管家 › 權限隱私 › 自啟動管理，打開「允許自啟動」「允許關聯啟動」（語音總控呼叫、開機後重排提醒都需要）
   - 按「測試提醒」，5 秒後應該跳出通知
4. **加入桌面小工具**：設定頁「桌面小工具 › 加入桌面」，或長按桌面 › 小工具 › 待辦清單

## 怎麼用
- **清單總覽**：最上面是「我的一天」「重要」「已排定」「全部」四個智慧清單，下面是你自己的清單。按下方「新增清單」建立；**長按清單**可以改名、換顏色、刪除（預設清單「工作」不能刪）
- **新增待辦**：清單最下面的「新增工作」，按 Enter 可以連續新增。在「我的一天」新增會自動加入我的一天；在「重要」新增會自動標星號；在「已排定」新增會設今天到期；沒指定清單的放「工作」
- **打勾完成**：點左邊圓圈。完成的待辦收在最下面「已完成」。重複的待辦打勾後會自動產生下一次，並提示是哪一天（可按復原）
- **星號**：點右邊星星標為重要
- **待辦詳細**：點待辦本身。可以改標題、加步驟、加入我的一天、設提醒（先選日期再選時間）、設到期日（今天／明天／下週一／選日期）、設重複（每天、平日、每週可選星期、每月、每年，可設間隔）、移到其他清單、寫備註、刪除
- **排序**：清單右上角「依到期」可以改成手動排序（拖右邊的 ≡ 調整順序）、依重要、依建立時間、依字母；每個清單各自記住。依到期時會分成「已逾期、今天、明天、之後、沒有到期日」，每段可以收合
- **長按多選**：長按一件待辦進入多選，上方「已選 N／全選／取消」，下方「完成、我的一天、移動、刪除」
- **刪除與復原**：刪除後畫面下方會出現約 10 秒的「復原」
- **我的一天**：每天自動清空（待辦本身不會刪）。空的時候按「看建議」可以把逾期、今天到期、昨天沒做完的加進來
- **搜尋**：清單總覽右上角放大鏡，會搜標題、步驟、備註
- **小工具**：點標題「清單名稱▾」選要顯示哪個清單（每個小工具各自記住，可以放好幾個）；點圓圈直接完成；點「＋」打開 APP 新增；點待辦名稱打開詳細
- **通知**：提醒時間到會跳通知，可以直接按「完成」或「10 分鐘後再提醒」

## 備份與同步
- 資料存在雲端資料庫（Supabase），換手機只要登入就會回來；APP 本機只是快取
- 斷網時照常可以新增、打勾、修改，連上網路後自動同步（清單總覽上方會顯示「N 筆等待同步」）
- 登入權杖用 Android Keystore 加密，不進系統備份
- 匯出備份檔（zip）在下一版

## 常見問題
- **一直顯示「帳號尚未開通」**：新帳號要先加入白名單，見「第一次使用」第 2 步
- **收不到驗證碼信**：看垃圾郵件；Supabase 預設寄信額度很低，若一直收不到，要在 Supabase 後台設定自訂 SMTP（見 PROJECT_STATUS.md 的待辦）
- **提醒沒響或晚響**：設定頁的「精準提醒」「電池最佳化」「通知權限」都要綠燈，ColorOS 要允許自啟動
- **小工具沒更新**：APP 改完會立刻更新小工具；若是網頁改的，要等同步（開啟 APP 或最多 15 分鐘）
- **語音總控說找不到待辦 APP**：兩個 APP 要同一把簽章（都從 GitHub Releases 安裝即可），ColorOS 要允許關聯啟動
- **隱私**：待辦內容存在 Supabase（美國公司、東京機房）。依你的資料規範，人事資料（姓名＋生日、身分證字號、薪資、考績、請假原因等）請不要寫進待辦
