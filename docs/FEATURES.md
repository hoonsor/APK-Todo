# 功能清單 — 待辦事項（57 號專案）

目標：Microsoft To Do 的替代品。介面與操作盡量比照 To Do，額外功能先不做。
資料唯一來源＝Supabase；入口有四個：Android APP、桌面小工具、網頁（電腦）、語音總控。
優先：P0＝第一版必備、P1＝下一步、P2＝之後。「倬確認」欄空白＝2026-10-24。

倬 2026-10-24 已確認：清單可自訂、小工具可切換清單、重要＋到期日、提醒＋重複、我的一天、步驟＋備註、第一版就做網頁、不搬 Microsoft To Do 舊資料、語音可新增＋查詢＋打勾。
